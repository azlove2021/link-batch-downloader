# 链接批量下载器

给一个文件夹，自动扫描里面所有 `.txt` 的下载链接，批量下载，**每个 txt 旁边自动建一个同名文件夹**存放成果。

**一个 HTML 文件，双击就能用。** 不用装 Python、不用装 Node、不用起服务、不用打包。

```
文档清单/
├── R5300.txt          <- 你的原始清单
├── R5300/             <- 自动创建，存放 R5300.txt 里的所有下载
│   ├── 产品白皮书.pdf
│   ├── 硬件描述.pdf
│   └── ...
├── R5500G5.txt
└── R5500G5/
    └── ...
```

---

## 快速开始

1. 下载 `链接批量下载器.html`
2. **双击它**（用 Chrome 或 Edge 打开）
3. 点「浏览…」选文件夹 → 点「扫描链接」→ 点「开始下载」

> ⚠️ 必须用 **Chrome / Edge（86+）**。**Firefox 和 Safari 用不了** —— 它们不支持浏览器直接写本地文件夹。打开时页面顶部会告诉你当前浏览器行不行。

## 下载目录

默认下载到「源文件夹\<txt 名>\文件」：

```
源文件夹/
├── R5300.txt
└── R5300/
    └── 产品白皮书.pdf
```

如果想下载到别的地方，步骤 1 第二行「下载到」右边点浏览，选个目录即可。再次选源文件夹时点旁边的「重置」恢复默认。

## 支持的 txt 格式

两种都行，同一个文件里混着写也可以：

```
# 格式一：一行一个纯链接
https://example.com/files/产品白皮书.pdf
https://example.com/files/硬件描述.pdf

# 格式二：序号 + 标题 + 链接
1. 产品白皮书  https://example.com/files/a.pdf
2、硬件描述    https://example.com/files/b.pdf
```

有标题就用标题做文件名，没标题就用链接里的文件名。文件名里的非法字符（`\/:*?"<>|`）自动替换，重名自动加 `(2)`、`(3)` 后缀。

## 选链接的几种姿势

- **单个**：点 checkbox，toggle 那一行
- **Shift 范围**：单击设锚点，Shift+点另一个 → 锚点到当前之间同向选中
- **拖拽**：在任务行上按住鼠标拖动，扫过的行同向选中；不拖则视为单击
- **按钮**：`全选` / `全不选` / `反选` / `只选失败`（只勾之前失败/暂停/未下的，方便重试）
- **分组折叠**：点每个 txt 分组的标题行折叠/展开；点 checkbox 不会误触折叠

下载按钮上会显示当前已选数量，比如 `开始下载（已选 3）`，一眼能看出下的是哪部分。

## 同名文件怎么处理

工具栏「同名文件」下拉框，三种策略：

| 选项 | 行为 |
|---|---|
| **续传（推荐）** | 文件不完整就从断处补；**已完整就直接跳过，一个字节都不重写** |
| 跳过 | 只要文件存在就跳过，不管完不完整 |
| 重新下载 | 无视已有文件，从头下一遍 |

## 跳过与续传的原理

判断一个文件是不是已经下完，不能只看"文件在不在"——万一上次下到一半就断了。

本项目用**服务端响应码**判定，不用额外的 HEAD 探测：

```
发 Range: bytes=<已下字节>- 请求
  → 206 Partial Content      → 没下完，接着续传
  → 200 且 Content-Length == 本地大小  → 已完整，跳过（不重写文件）
  → 200 且 Content-Length != 本地大小  → 服务器不支持 Range 或文件异常，从头下
```

**为什么不用 `Content-Range`？** 因为它不在 CORS 默认暴露的响应头里，浏览器 JS 读到的是 `null`。只有 `Content-Length` 是安全头，能读到。这个坑踩过一次，详情见下方踩坑记录。

## 技术栈

| | |
|---|---|
| 语言 | 原生 HTML + CSS + JS，**单文件，零框架、零外链、零构建** |
| 文件读写 | [File System Access API](https://developer.mozilla.org/zh-CN/docs/Web/API/File_System_Access_API) —— 直接读写本地文件夹，无需服务端 |
| 下载 | `fetch` + `ReadableStream` 流式写入，**边下边存盘，不占内存**（下 4 GB 文件也不会爆内存） |
| 续传 | HTTP `Range` 请求 + `FileSystemWritableFileStream.seek()` |
| Excel 导出 | 用浏览器内置 `CompressionStream` **手写 xlsx**（ZIP + DEFLATE），不引第三方库 |
| 依赖 | **无** |

## 为什么是纯前端

最初版本是 Python 后端 + 浏览器前端。改成纯前端后：

- 不用装 Python，不用起服务，不用管端口冲突
- 双击 HTML 就能用，拷给别人一个文件就完事
- 下载由浏览器负责，天然流式落盘

代价是**只用 Chrome / Edge**。对这个场景，值。

## 踩过的坑

都是实际踩到、已解决的问题，改代码时留意：

1. **URL 里的空格会截断链接** —— 中文文件名常带空格（`中兴 R5300 白皮书.pdf`），正则用 `\S+` 会在空格处截断，导致 **841/917 条链接全部变 404**。必须从 `http` 一直取到**行尾**。
2. **`Content-Range` 读不到** —— 它不在 CORS 默认暴露头里，浏览器 JS 拿到 `null`。改用 `Range` 请求的**状态码**判定是否下完（见上方原理）。
3. **续传时文件会被白白重写** —— 早期版本即使判断出"已完整"，也会打开文件写入一遍，导致 mtime 变化。现在完整命中直接 `return`，不碰文件。
4. **速度显示反复归零** —— 用 `本次增量 / 间隔` 算瞬时速度，网络 chunk 间隔一旦超过采样周期就显示 0。改用 **EMA 平滑**（`新值 = 旧值 * 0.7 + 瞬时 * 0.3`）。
5. **通知堆叠把页面顶飞** —— 每次操作都 append 一条通知，越堆越多。改成**只保留最新一条**，info/warn 3.5 秒自动消失。
6. **进度百分比出现小数** —— 显示成 `2.1993%`，必须 `Math.round`。
7. **折叠失效因为 class 加错位置** —— CSS 是 `.grp.cl .tk {display:none}`，但 onclick 把 `cl` 加到了内部 `.grp-h`。给外层 `.grp` 加 `cl` 才生效（同时给 `.grp-h` 加一份用于旋转箭头）。
8. **HTMLInputElement.click() 提前 toggle** —— `cb.click()` 在 dispatchEvent **之前**已经把 `cb.checked` 翻转了，listener 看到的是 toggle 后状态；而真实鼠标点击，listener 看到的是 toggle 前状态。统一处理：在 `mousedown` 里记 `pre` + `shift`，在 `click` 里用记录的 pre 算 target，并 preventDefault 阻止 click 的默认 toggle。
9. **`onchange` 不带 modifier** —— Shift 键状态只能从 `mousedown/click` 拿到，`onchange` 事件的 `ev.shiftKey` 永远是 undefined。
10. **MD5 填充长度算错** —— 早期版本用 `padLen = (len<56) ? 56-len : 120-len`，对 `len >= 120` 会算出**负数**直接崩溃。正确公式：`z = (55 - (len & 63) + 64) & 63`，`padLen = 1 + z`。这是 RFC 1321 的标准填充边界，漏算 len=56/120 这类临界点很容易踩。
11. **大文件经 CDP 传 Array 会 OOM** —— Playwright 的 `exposeFunction` 把 JS 数组经 JSON 序列化跨进程传，2MB 的 PDF 转成 200 万元素的数组会撑爆 Node（实测 segfault）。改成 `__fs_read` 返回 base64 字符串，浏览器侧 `atob` 解码，大文件也安全。

## 常见问题

**Q：为什么 Firefox / Safari 打不开？**

它们不支持 File System Access API（浏览器直接写本地文件夹）。这是浏览器能力限制，绕不过去。**请用 Chrome 或 Edge。**

**Q：下载到一半断网了/关窗口了怎么办？**

重新打开，选同一个文件夹，点扫描再点开始。已下完的跳过，没下完的续传。

**Q：暂停和停止有什么区别？**

- **暂停**：立即中断，已下部分保留在源文件里，点「继续」从断点接着下
- **停止**：中断整轮任务。再点开始会接着下（已完成的不重复，没下完的续传）

**Q：扫出来的链接 404？**

先确认 txt 里链接本身没被换行拆成两半。中文+空格的情况本项目已处理，但如果你的 txt 里链接被强制换行就没救了。

**Q：能下需要登录的链接吗？**

不能。只支持公开直链，不带 Cookie / 鉴权。

**Q：下载的文件在哪？**

就在你选的文件夹里，每个 txt 旁边一个同名子文件夹。

**Q：文件夹权限每次都要重新授权吗？**

Chrome 会记住。同一文件夹通常只在第一次点「浏览」时确认一次。
